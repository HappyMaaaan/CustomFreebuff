    How it works — and why it is safe
    
    
      
  • Display only. The studio injects a stylesheet into the Freebuff window, the way a browser extension styles a page. No file of the application is modified, patched, or replaced.
    • 
      
  • Nothing is bypassed. The native window color goes through Freebuff's own official theme API (window.freebuffDesktop.setTheme) — exactly the built-in dark/light setting.
    • 
      
  • The debug port is local. --remote-debugging-port listens on 127.0.0.1 only. It is the same DevTools mechanism the application itself uses internally.
    • 
      
  • Nothing leaves your machine. The theme never touches accounts, sessions, or the app's requests. Server-side, Freebuff sees exactly the same traffic as before.
    • 
      
  • Everything is reversible. "Restore original look" removes the CSS and puts the native theme preference back. Without the studio, Freebuff is strictly the original app.
    • 
      
  • Tip: always launch Freebuff from the studio (green button) — that is what activates the theme. You can close the studio afterwards; the theme stays until the app reloads its page.
